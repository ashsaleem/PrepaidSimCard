# Prepaid SIM Card Management System

A C++ project that simulates a prepaid SIM card management system using Object-Oriented Programming concepts.

## Features

- SIM card activation and blocking
- Balance tracking and recharge
- Data allowance management
- Data consumption tracking
- Validity period management
- Additional data usage charges
- Custom string copying and comparison functions

## Concepts Used

- Classes and Objects
- Constructors
- Member Functions
- Encapsulation
- Conditional Statements
- Character Arrays
- Pointers
- Modular Programming
- Header and Source Files
